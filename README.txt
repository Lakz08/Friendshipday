Friendship Day Website

How to use:
1. Open index.html in a browser, or upload the folder to GitHub Pages / Netlify.
2. Replace the meme placeholders inside the memes/ folder with your own image files.

Suggested meme filenames:
- crying-cat.jpg
- reels-cat.jpg
- chaos-cat.jpg

Suggested search terms for meme downloads:
- crying cat meme
- cat looking shocked meme
- reels meme cat
- chaos cat meme
- dramatic cat meme

Optional tweaks:
- Edit the text in script.js to add more inside jokes.
- Change the nickname “Kuttee” anywhere you want in the code.
- You can add more questions by editing the questions array in script.js.
